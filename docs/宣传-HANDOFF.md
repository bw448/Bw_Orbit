# Orbit 宣传素材 HANDOFF

给新对话用：做宣传片、公众号推文、抖音简介时，先读这份，再读 `README.md`。

## 1. 一句话定位

Orbit 是一个按 **“学期 → 科目 → 学习方式”** 组织的 GIS 本科学习站，不是资料堆。

- 在线：https://bw448.github.io/Bw_Orbit/
- 仓库：https://github.com/bw448/Bw_Orbit
- 性质：个人学习项目，免费、无登录、无广告；学习记录只存在本机浏览器。
- 边界：不是学校官方平台，不承诺押题/保过；教材与课程资料版权归原作者。

## 2. 可公开的事实清单

| 科目 | 内容 |
|---|---|
| 遥感 | 8 章知识脉络、7 套完整作业、90 题、75 条中英术语、61 条讲义补充 |
| Python | 599 题 / 10 套卷、整卷阅读与下载、代码练习、AI 助教 |
| Python 知识地图 | 10 个知识模块、题库主题覆盖、真实结构 100 分模拟卷、主题练习 |
| 毛概 | 1065 题系统题库 + 100 道 2024/2025 真题 + 256 条高频考点 + 39 组易混 + 118 道大题背诵 |
| ArcGIS | 80 道客观题 + 10 道简答 + 7 道分析 + 18 条名词解释 + 4 个算法 + 6 个实操流程 |
| 自然地理学 | 老师勾画重点、章节框架、变质作用扫描、重点页 |
| 概率论 | 章节重点、公式、PPT 原题、2022—2023 期末卷 |
| 电子书 | 5 本大二上教材，全页图片阅读，50 页分卷下载，完整版可下载 |
| 总纲 | 桌面 `系统整理好的复习资料/`，一科一份 docx，随网站内容同步 |

技术事实：

- 纯静态 HTML/CSS/JS，GitHub Pages 部署，手机 390px 可用。
- PWA：可添加到主屏，核心页面离线可用。
- AI：全站共用一个 DeepSeek Key，Key 只存本机 `localStorage`；没有 Key 也能用全部题库。
- 新题库支持：随机 20 题、今日复习（1/3/7/14/30 天）、收藏、重做、导出/导入。
- 毛概 / ArcGIS / 自然地理 / 概率论 / Python 知识地图都有“问 AI”：右下角按钮、章节旁按钮、选中文字直接问。

## 3. 宣传片方向

### 30 秒竖屏（抖音）

主题：**“期末六门课，别在六个文件夹里翻。”**

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0—3s | 桌面一堆课程文件夹快速切换 | 期末复习，资料散在六个文件夹？ |
| 3—7s | 首页 → 学期 → 大二上 → 六门课 | 有人把它做成了一个网站。 |
| 7—12s | 遥感作业、Python 599 题、毛概 1065 题快切 | 作业、题库、术语、真题，按科目放好。 |
| 12—18s | 毛概高频考点 → 大题背诵 → 易混对比 | 选择题有题库，大题按得分点背。 |
| 18—24s | 手机端刷 ArcGIS 题 + 点“问 AI” | 手机能刷，不会的可以直接问。 |
| 24—30s | Logo + 网址 | Orbit · 地信学习站，链接在主页。 |

拍摄建议：

- 竖屏 1080×1920；桌面录屏用 1440×900，手机录屏用 390×844。
- 只录真实操作：点选项、翻考点、展开大题、打开 AI 面板。
- 不出现 API Key、个人微信、老师姓名、同学信息。
- 字幕大、句子短；不要“全网最强/保过/押题”这类词。

### 60—90 秒横屏（公众号/视频号）

结构：

1. **痛点**：六门课、十个文件夹、期末周不知道先看哪个。
2. **是什么**：不是网盘，是“学期→科目→学习方式”的三层结构。
3. **六科各给一个镜头**：遥感作业、Python 599、毛概选择题+大题、ArcGIS 80 题、自然地理勾画、概率论 PPT 原题。
4. **两个差异点**：手机能刷；不会的可以直接问 AI。
5. **边界**：个人项目、免费、无登录、不是官方。
6. **CTA**：网址 + “先收藏，期末周再用”。

## 4. 公众号推文

### 标题备选

- 《我把大二上六门课，塞进了一个网站》
- 《期末周，别再翻六个文件夹了》
- 《一个 GIS 学生的复习站：题库、作业、总纲和 AI》
- 《从遥感作业到毛概大题，我把复习资料重新排了一遍》

### 结构

1. **开头故事**：自己复习时，资料在 PPT、PDF、Word、聊天记录里来回找；于是做了一个按科目组织的站。
2. **它不是什么**：不是资料网盘，不是学校官方，不卖课。
3. **它是什么**：三层结构 + 六科模块 + 手机端 + AI 速查。
4. **六科分别怎么用**：
   - 遥感：先看章脉络，再做作业，最后刷 90 题。
   - Python：599 题按套刷；知识地图补 Matplotlib/GeoPandas/GDAL。
   - 毛概：高频考点→系统题库→真题→大题背诵。
   - ArcGIS：80 道客观题→名词解释→算法→实操→简答/分析。
   - 自然地理：老师勾画优先。
   - 概率论：PPT 原题优先。
5. **两个小功能**：手机刷题；选中文字问 AI。
6. **使用方式**：打开网址即可；无登录；学习记录在本机；没有 AI Key 也能用题库。
7. **边界与版权**：个人学习项目；教材/课程资料版权归原作者；答案以教材和老师为准。
8. **结尾**：网址 + 二维码（如有）+ “先收藏”。

## 6. 录制前检查

1. `cd E:\地信复习系统 && .\start.bat`，用 `http://localhost:8765/` 录制，避免 `file://` 限制。
2. 浏览器清一次缓存或开无痕窗口，确保是最新版本。
3. 手机录屏前先刷新，确认底部没有旧 Service Worker 缓存。
4. 准备一个演示用 DeepSeek Key；录 AI 时不要拍到完整 Key。
5. 关闭微信/QQ 弹窗、桌面个人文件；只保留网站窗口。
6. 录完检查：没有个人信息、没有老师姓名、没有未授权教材大段内容。

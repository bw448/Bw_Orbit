01 / WHAT IT IS

不是课程平台，
是一份公开的学习记录。

我把上课用到的课件、作业、真题和错题整理进来，按“学期 → 科目 → 题型”放好。它不是学校官方平台，也不承诺覆盖考试范围；它只记录我学到哪、练到哪。

05 / FAQ

几个常见问题。

如果这里没有答案，去开源项目页找我的 GitHub，或者直接在“BW有话说”里看看我最近在做什么。

需要注册或登录吗？

不需要。Orbit 没有账号系统，也不收集你的身份信息。打开网页就能用；错题、收藏和进度都记在当前浏览器里。

换手机或换电脑，进度会同步吗？

不会。进度存在浏览器的 localStorage 里。清缓存、换设备或换浏览器，记录不会跟过去。毛概 / ArcGIS / 自然地理 / 概率论在题库面板里有“导出 / 导入”；Python / 遥感在右下角“学习 → 数据”里导出 / 导入。

手机上能用吗？

能。页面按 390px 宽度适配；顶部有“菜单”按钮，课程页有大标签。也可以把网站“添加到主屏幕”，当成一个简单的 PWA 用。

内容全吗？答案一定对吗？

不全，也不保证全对。这是我按自己的课程进度整理的内容，不是学校官方平台，不承诺押题或覆盖全部考点。大多数题目来自课程资料和真题；自然地理 80 题、概率论 60 题是自编自测题。遇到争议，以教材和老师讲解为准。

“问 AI”怎么开？

需要你自己的 DeepSeek API Key。在课程页或 Python 页打开“问 AI”，点“API Key / 设置”填入即可。Key 只存在本机 localStorage，请求直接发往 api.deepseek.com，不经过 Orbit 的服务器。没有 Key 也不影响刷题。

能离线用吗？

部分可以。首次打开后，常用页面和脚本会被 Service Worker 缓存；断网刷新仍能打开已缓存的页面。PDF、Word 和视频不缓存，需要联网下载。

为什么有的学期是空的？

还没上到。大二下、大三上、大三下先留了入口；课程、作业和教材确定后再按同一套结构接进来。网站会跟着我的学习进度继续长。

ONE MORE THING

Orbit 不指望有很多人用。
它更像一份公开的学习笔记。

我学到哪，网站就长到哪。如果它刚好对你有用，就从一门课、一组题开始；如果只是想看看一个人怎么把学习留下来，也可以随便逛逛。

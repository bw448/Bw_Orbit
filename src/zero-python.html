第 0 课

程序，
在做什么？

先不用背语法。先知道三件事：输入、处理、输出。

程序就是一套“输入 → 处理 → 输出”的指令。你给它数据，它按步骤处理，再给你结果。比如输入成绩，算出平均分，输出分数。

变量是给数据起的名字。把数据放进一个盒子，之后用名字取出来；盒子里的东西可以换，名字不变。

函数是把一段处理包起来，起个名字。下次要用，不用重写一遍，直接叫名字。程序就是这样从“一行行”变成“一块块”的。

所以学 Python 不是背语法，而是学会把一个问题拆成：要什么输入 → 做什么处理 → 输出什么。后面的每一节，都是在补其中一块。

三个词：输入变量函数

怎么持续学

不跳步，
每节留一个动作。

从 0 到 1 不是看完一篇文章，而是持续学习。每一节只做三件事：懂一个概念、写一行代码、记一个疑问。

CONCEPT

先懂一个概念

不追求一次学完；每节只抓一个核心概念。

CODE

再写一行代码

看懂不算会；自己敲一遍，改一个参数。

ASK

留一个疑问

卡住就问 AI，让它换一种说法或举一个例子。
